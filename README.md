# NPU_GC — 智能物流搬运机器人下位机（2025 工创赛）

西北工业大学 2025 年中国大学生工程实践与创新能力大赛「智能物流搬运机器人」备赛代码，该作品获省级一等奖。本仓库承载**下位机运动控制**（STM32F103ZE）；二维码读取与靶心识别在上位机完成，识别结果经串口命令下发至本控制器执行。

> 本仓库快照停留在 2024-12 备赛初中期：此版本为**步进电机开环 + 陀螺仪偏航纠偏**方案，比赛后期底盘控制的进一步迭代不在本仓库内。代码按参赛时状态原样归档（含已知问题，见文末）。

## 仓库结构

| 目录 | 工程 | 说明 |
|---|---|---|
| `car2/` | 主车工程（参赛主版本） | 行车 / 升降 / 机械爪 / 转盘 / 陀螺仪纠偏全功能 |
| `HWT101/` | 陀螺仪验证工程 | 早期单板验证工程（UART4 未启用，见已知问题） |
| `HWT101-copy/` | 历史快照 | 加入陀螺仪方案前的旧版本，留作回滚备份 |

## 硬件架构

- **MCU**：STM32F103ZE @ 72 MHz（Keil MDK / ARMCC5，-O0，JLink）
- **执行器**：8 路两相步进电机（16 细分 = 3200 步/圈，step/dir 开环驱动，梯形加减速 [AVR446](https://ww1.microchip.com/downloads/en/AppNotes/doc8017.pdf) 状态机）+ 3 路舵机（TIM5，50 Hz）+ 机械爪升降 / 抓取 / 翻转
- **感知与交互**：HWT101 陀螺仪（UART4，维特智能协议，偏航角纠偏）、0.96″ OLED（软件 I2C）、WS2812 灯带（SPI1 + DMA）、串口屏（USART2，USART HMI 指令集）
- 无编码器反馈：位置控制 = 脉冲计数（开环），靠陀螺仪消除行进偏角

### 定时器与引脚映射

| 定时器 | 通道 → 引脚 | 用途 |
|---|---|---|
| TIM2（完全重映射） | CH3→PB10 / CH4→PB11 | step1 / step2（升降组） |
| TIM3（完全重映射） | CH1-4→PC6 / PC7 / PC8 / PC9 | step3 / step4 / step7 / step8（行车组） |
| TIM4（无映射） | CH3→PB8 / CH4→PB9 | step5 / step6（载物台等） |
| TIM5（无映射） | CH2-4→PA1 / PA2 / PA3 | servo1 / servo2 / servo3 |

方向与使能引脚、完整引脚表见 `car2/README.TXT`（GB2312 编码）。

## 通信协议

| 串口 | 引脚 | 波特率 | 对端 | 帧格式 |
|---|---|---|---|---|
| USART1 | PA9 / PA10 | 115200 | 上位机 | `0xFF + 8B 载荷 + 0xFE`，载荷 [0] 为命令字 |
| USART2 | PD5 / PD6 | 115200 | 串口屏 | 接收 `0xAF + 8B + 0xAE`；发送 USART HMI 指令 + `0xFF×3` 终止 |
| UART4 | PC10 / PC11 | 115200 | HWT101 陀螺仪 | `0x55 + 类型 + 8B 数据 + 累加和`（11 B），0x53 帧取偏航角 |

## 上位机命令字（USART1）

| 命令 | 功能 |
|---|---|
| `0x01` / `0x02` | x / y 方向位移 |
| `0x03` | 角度：消除行进偏角 + 精准转角（陀螺仪两轮校验） |
| `0x04` | 二维码数据 |
| `0x05` / `0x06` | 靶心识别 x / y 方向修正 |
| `0x07` / `0x08` | 从转盘 / 从地面抓取物块 |
| `0x09` / `0x0A` | 放置物块第一层 / 第二层 |
| `0x0B` | 到达指定位置（子命令 0x01-0x04） |
| `0x0C` | 移动距离（子命令：三维修 / 载物台 / 靶心识别 1 / 靶心识别 2） |

## 构建

1. Keil MDK（ARMCC v5）打开 `car2/USER/Template.uvprojx`
2. 源文件为 **GB2312 编码**，编辑器需正确设置编码后再改动
3. JLink 下载调试；`OBJ/` 内含当时可刷写的 hex/axf 历史产物（约 90 MB，按原样归档未清理）

## 已知问题（历史代码，按参赛状态归档不修复）

- `contral.c` case 0x03 的纠偏重试条件 `(angle+90)*10 <= 25 || >= -25` 恒真，重试分支实际永不执行；且校验使用的是转动前的角度快照
- 多处 `while(stepPosition == distance)` 阻塞等待无超时；与中断共享的变量未加 `volatile`，正确性依赖 -O0 编译等级
- UART3（PB10/PB11）与 TIM2 重映射的步进脉冲引脚冲突，该串口初始化后未实际使用
- `HWT101/` 工程未调用 `UART4_Init`，该工程内陀螺仪解析不激活（陀螺仪仅在 car2 主工程启用）
